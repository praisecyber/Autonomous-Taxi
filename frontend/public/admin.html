Backups and restoration

Stop the server before administration commands. Backups contain private account and trip data. Keep them outside Git and use a new output path.

.venv/bin/python -m taxi.manage backup --source runtime/taxi.sqlite3 --output runtime/backups/taxi-copy.sqlite3
.venv/bin/python -m taxi.manage restore --source runtime/backups/taxi-copy.sqlite3 --output runtime/restored.sqlite3

Restore checks integrity, migrates supported schemas, revokes sessions and interrupts active trips. Verify the restored copy before selecting it as the server database. See docs/ADMIN-ACCOUNTS.md for the full procedure.
